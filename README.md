# 📘 StudyNotion – EdTech Platform

**StudyNotion** is a full-fledged EdTech platform designed to bridge the gap between teachers and students by enabling seamless online course creation and enrollment. It provides both a modern Web application and a cross-platform Mobile application (React Native), powered by a scalable Node.js & PostgreSQL backend.

## 🚀 Features

- 👨‍🏫 **Instructors:** Create, manage, publish courses, create exams (MCQ & Written), grade submissions, and view leaderboard.
- 👩‍🎓 **Students:** Browse courses, enroll, track lecture progress, take exams, download lecture notes and course certificates.
- 💬 **Community Doubt Forum:** Post doubts with image screenshots, discuss with instructors and peers, and mark resolved.
- 📱 **Mobile Application:** Dedicated native Android mobile application with instant sync.
- 🔐 **Authentication:** JWT authentication and role-based access (Admin / Instructor / Student).
- 💳 **Payments:** Integrated payment processing.

---

## 🛠 Tech Stack

- **Web Frontend:** React.js, Tailwind CSS, Redux Toolkit, Vite
- **Mobile App:** React Native, NativeWind, React Navigation
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL (Raw SQL Queries & connection pool)
- **Cloud Storage:** Cloudinary (Media and lecture resources)
- **Version Control:** Git, GitHub

## 🧑‍💻 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/nurmohammadapu/Ius-project-one.git
   cd Ius-project-one
   ```

2. **Frontend Setup**
   ```bash
   npm install
   npm start
   ```

3. **Backend Setup**
   ```bash
   cd server-two
   npm install
   npm run dev
   ```

4. **Mobile App Setup**
   ```bash
   cd mobile-app
   npm install
   npm run android
   ```
